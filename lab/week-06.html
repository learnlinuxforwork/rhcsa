Lab guide 6

Logs, Journals, and Time

Find out what a system has been doing, make that record survive a reboot, and keep the clock correct.

2-3 hours Week 5 complete
Before you start
  • Week 5 complete
  • Both machines reachable
  • Take a snapshot of both machines. You will break things on purpose.

1. Read the journal

journalctl is the primary tool. Learn the filters rather than scrolling.

Filter by unit, priority, and time
sudo journalctl -u sshd --no-pager | tail -20
sudo journalctl -p err --no-pager | tail -20
sudo journalctl --since '1 hour ago' --no-pager | tail
sudo journalctl --since '2026-08-01 09:00' --until '2026-08-01 17:00' --no-pager | tail
Follow live, and look at a specific boot
sudo journalctl -f    # Ctrl-C to stop
sudo journalctl --list-boots
sudo journalctl -b -1 --no-pager | head
Kernel messages and a specific executable
sudo journalctl -k --no-pager | tail
sudo journalctl /usr/sbin/sshd --no-pager | tail -5

2. Make the journal persistent

By default the journal may live only in memory and vanish at reboot. Preserving it is an explicit objective.

Create the directory and configure it
sudo mkdir -p /var/log/journal
sudo systemd-tmpfiles --create --prefix /var/log/journal
sudo sed -i 's/^#\?Storage=.*/Storage=persistent/' /etc/systemd/journald.conf
grep -i storage /etc/systemd/journald.conf
Restart and confirm
sudo systemctl restart systemd-journald
sudo journalctl --list-boots
ls -ld /var/log/journal/*
Worth knowing

After a reboot, 'journalctl --list-boots' should show more than one entry. If it only ever shows the current boot, persistence is not working.

3. Traditional log files

rsyslog still writes plain text files that some tasks reference by name.

What is there
sudo ls -l /var/log/
sudo tail -20 /var/log/messages
sudo tail -20 /var/log/secure
sudo grep -i 'authentication failure' /var/log/secure | tail
Generate an entry and find it in both places
logger -p user.notice 'RHCSA lab test message from shea'
sudo grep 'RHCSA lab test' /var/log/messages
sudo journalctl --no-pager | grep 'RHCSA lab test'

4. Time services

chrony is the client. Configure it, then prove synchronisation.

Install, enable, and inspect
sudo dnf install -y chrony
sudo systemctl enable --now chronyd
chronyc sources -v
chronyc tracking
Point at a specific server
sudo cp /etc/chrony.conf /root/chrony.conf.backup
sudo sed -i '/^pool /d' /etc/chrony.conf
echo 'server time.cloudflare.com iburst' | sudo tee -a /etc/chrony.conf
sudo systemctl restart chronyd
sleep 5
chronyc sources
Timezone and clocks
timedatectl
timedatectl list-timezones | grep -i new_york
sudo timedatectl set-timezone America/New_York
sudo timedatectl set-ntp true
timedatectl

5. Secure file transfer

Named in the objectives, and you will use it constantly anyway.

Three ways to move a file to the second machine
echo 'transfer test' > ~/transfer.txt
scp ~/transfer.txt shea@serverb:~/
rsync -av ~/lab01/ shea@serverb:~/lab01-copy/
sftp shea@serverb <<'EOF'
put ~/transfer.txt remote-via-sftp.txt
ls
bye
EOF
Confirm from the far end
ssh shea@serverb 'ls -l ~/transfer.txt ~/remote-via-sftp.txt; ls ~/lab01-copy | head'

Verify your work

Run these before you consider the lab finished.

  1. sudo journalctl --list-boots # more than one line after a reboot
  2. ls -d /var/log/journal/*
  3. chronyc tracking | head -3
  4. timedatectl | grep -E 'Time zone|synchronized'
Break it, then fix it

Break:

sudo sed -i 's/^Storage=persistent/Storage=volatile/' /etc/systemd/journald.conf && sudo systemctl restart systemd-journald && sudo reboot

What you'll see: After the reboot, 'journalctl --list-boots' shows only the current boot. Yesterday's evidence is gone.

Fix:

sudo sed -i 's/^Storage=volatile/Storage=persistent/' /etc/systemd/journald.conf && sudo systemctl restart systemd-journald

Why it matters: 'Preserve system journals' is a real objective, and volatile storage silently discards everything at shutdown. The verification is always the same: reboot, then list boots.

Now reboot

Run sudo reboot, then re-run every command in the verify list above. Anything that did not come back on its own would have scored zero on the exam. Fix it now, while you can still see what you did.
